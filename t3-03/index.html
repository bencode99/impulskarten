Aufgabe 03 B/C · Block 1 · Starter v9
Denkimpuls
Verfuegbar muss größer gleich Ihrer Fehlmenge sein. Liefertage muss kleiner gleich 1 sein. Verbinden Sie beide Bedingungen mit AND.
Weitere HilfeHilfe

Größer gleich schreibt man >=, kleiner gleich <=. Setzen Sie für Fehlmenge Ihre Zahl aus Aufgabe 02 B ein.

SELECT *
FROM Lieferangebot
WHERE Modell = 'NX-65R'
  AND Verfuegbar >= Fehlmenge
  AND Liefertage <= 1

Weiter bei 03 D: Ergänzen Sie hinter SELECT * ein Komma und die Rechnung. Keine Umbenennung und keine Sortierung erforderlich.
SELECT *, Fehlmenge * Einzelpreis + Versandkosten

Die letzte Ergebnisspalte enthält den Gesamtpreis. Vergleichen Sie die drei Werte und wählen Sie den kleinsten.

Aufgabe 03 · Block 2
Denkimpuls

Das richtige Modell, ausreichend Stück und Lieferung spätestens morgen müssen gleichzeitig passen.

Weitere Hilfe öffnen

Ersetzen Sie Fehlmenge an beiden Stellen durch Ihre Zahl aus 02 D. Hinter SELECT * folgen ein Komma und die Rechnung. Mit AS Gesamtpreis benennen Sie die Spalte. ORDER BY Gesamtpreis stellt den kleinsten Preis nach oben.

SELECT *, Fehlmenge * Einzelpreis + Versandkosten
       AS Gesamtpreis
FROM Lieferangebot
WHERE Modell = 'NX-65R'
  AND Verfuegbar >= Fehlmenge
  AND Liefertage <= 1
ORDER BY Gesamtpreis

Wenn Sie nicht weiterkommen, fragen Sie die Lehrkraft.
